Print Studio 0.3.12 fixes figures and following content disappearing from embedded notes during pagination.

- Long embedded notes containing tables and HTML figures now retain their diagrams, captions, and remaining text when flowing onto another page.
- The fix applies to the preview, exported HTML, Save PDF, and Print.
- Embedded note titles and properties still follow your existing visibility setting.

Requires **desktop Obsidian 1.13.0 or newer**.

Update through **Settings → Community plugins → Check for updates**, then update Print Studio. Reopen Print Studio and generate a fresh PDF to include previously omitted content.
